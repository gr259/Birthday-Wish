# 💗 Interactive 3D Beating Heart with Personalized Letter Editor A premium, interactive, single-page web experience featuring a 3D beating heart built dynamically from floating typography particles. The application includes a self-contained, glassmorphic customization panel allowing users to write personalized letters, save edits locally, and generate shareable links containing their custom letters. No backend database or compilation step is required—this is a 100% browser-native project built with vanilla web technologies. --- ## 🌟 Key Features * **3D Particle heart Simulation**: Renders a rotating, interactive 3D heart on an HTML5 canvas using dynamic mathematical formulas. Dragging or touching the screen rotates the heart in 3D space. * **Realistic Heartbeat Rhythm**: Features a double-pulse heartbeat cycle ("lub-dub") that dynamically scales the heart particles and glows in sync with synthesized audio. * **In-App Personalization Editor**: A subtle, elegant editing button transforms the letter overlay into a glassy configuration panel. Users can edit recipient names, sender names, and the letter body text. * **URL-based Sharing**: Generates unique shareable links. When a customized link is generated, all details are encoded into a safe base64 URL parameter. Opening the link immediately decodes the personalized text for the recipient. * **Persisted Customization**: Automatically preserves customized content locally using the browser's `localStorage` API. * **Fully Responsive Design**: Styled using modern CSS design tokens to ensure a premium look that scales flawlessly across mobile devices, tablets, laptops, and desktop screens. --- ## 🛠️ Technology Stack * **Markup**: HTML5 Semantic Structure * **Styling**: Vanilla CSS3 (Custom Properties, Glassmorphism, Responsive Flexbox, Keyframe Animations) * **Graphics**: HTML5 Canvas (2D Context, Coordinate projection, Z-sorting) * **Audio**: Browser-native Web Audio API (Synthesized low-frequency oscillator thuds and click resonances) * **State & Encoding**: JavaScript ES6 (URLSearchParams, Symmetrical Unicode Base64 Encoding) --- ## 🚀 Getting Started ### Prerequisites You only need a modern web browser. No installation, `npm install`, or Node.js environment is required. ### Local Development / Running 1. Clone or download this repository. 2. Open `index.html` in any web browser of your choice. --- ## 📝 Customization and Configuration ### Sharing Mechanics The URL sharing flow handles text and emoji compression completely in the client: 1. When you click **Copy Link**, the input values are serialized into a JSON object: ```json { "to": "Recipient Name", "from": "Sender Name", "msg": "Custom love letter message body..." } ``` 2. The JSON string is encoded using a UTF-8 safe base64 string: ```javascript const base64 = btoa(unescape(encodeURIComponent(JSON.stringify(data)))); ``` 3. A query parameter is attached to the current path: `https:///?d=` 4. Upon page load, the decoder checks for the `d` query parameter, decodes it symmetrically, and populates the text nodes, overriding defaults. ### Local Cache If no query parameters are found, the page checks `localStorage` for `love_to`, `love_from`, and `love_msg`. If these exist, they will load as the default values. If neither URL params nor local cache are present, it falls back to the default fallback configuration in `script.js`. --- ## 🎨 File Structure * [index.html](file:///d:/3D%20Beating%20Heart/index.html) - Structural framework, loading screens, and modals. * [style.css](file:///d:/3D%20Beating%20Heart/style.css) - Layouts, animations, and responsiveness. * [script.js](file:///d:/3D%20Beating%20Heart/script.js) - 3D Canvas engine, user interaction, Web Audio synthesizer, and URL parsing logic. * `README.md` - Documentation and project guidelines.
